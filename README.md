# Bad North - New Mode

BepInEx 模组：给《Bad North》加"投放敌舰 + 遥控敌方单位"两种玩法。

## 操作

- `F1`：开关投放菜单；菜单里左键点兵种、点数量。
- 菜单内：左键点兵种 → 左键点滩头陆地投放；`Esc` 或右键关闭菜单。
- `F2`：清场，销毁本模组投放的所有船与单位。
- 关闭菜单后，可遥控已投放的单位：
  - `Shift` + 左键或右键点单位：选中它所在的整队；再点同一队取消。
  - `R`：选中所有可遥控单位。
  - 左键或右键点地块：选中的单位集结前进；不同兵种各成一队，人多时占用相邻格。
  - 按住 `Alt` 拖动：框选。
  - 选中的单位会变慢时间，便于操作。
- 没有选中可遥控单位时，鼠标左右键与原版一致。
